# Pliant Guessing Game
A Python-based interactive guessing game where players attempt to discover a randomly generated secret number.

The game provides hints by informing players whether their guess is higher or lower than the secret number and offers additional feedback when they are close. Invalid inputs, including non-integer values, are handled and excluded from the attempt count.

Features include:

Single-player mode
Multiplayer mode
Multiple difficulty levels
Input validation
Attempt tracking
Customizable guessing ranges
